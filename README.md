# Focused-Fe

Frontend app built with [Vite](https://vite.dev/), [React](https://react.dev/), and TypeScript.

## Requirements

- Node.js 22+
- [pnpm](https://pnpm.io/) 10+

## Getting started

```bash
pnpm install       # install dependencies
pnpm dev           # start the dev server on http://localhost:5173
```

## Scripts

- `pnpm dev` — start the Vite dev server (HMR)
- `pnpm build` — type-check and build for production into `dist/`
- `pnpm preview` — preview the production build on http://localhost:4173
- `pnpm lint` — lint with [oxlint](https://oxc.rs/)
